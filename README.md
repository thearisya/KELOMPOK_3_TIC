# JUICY

JUICY is a responsive fruit and drink discovery website made as a Media Production final project at Universitas Indonesia.

It includes drink recipe discovery, Fruitpedia, an interactive ingredient mixer, fruit mini-games, and information about the project team and sources.

## Run it locally

Open `index.html` in a modern web browser. Keep the `assets` folder beside it; the site uses relative paths to load its images.

## Publish with GitHub Pages

This is a static website. It does not need a build step or server-side setup. Publish this folder as the repository root, with `index.html` at the top level, then enable GitHub Pages from the `main` branch and the `/(root)` folder.

The public site contains the project team portraits and all other files in this repository. Review the assets before publishing.
